Write a function `insertion_sort(values)` that takes a list of numbers and
returns a new list containing the same numbers in ascending order.

You must implement the **insertion sort** algorithm yourself: process the
input one element at a time, inserting each element into its correct position
among the elements you have already sorted. Do not use the built-in `sorted()`
function or the `list.sort()` method.

Your function must not modify the input list, and must handle an empty list
and lists containing duplicate values correctly.
